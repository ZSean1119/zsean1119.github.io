# Sean Zheng — Mechanical Engineering Portfolio

A new, independent dark-theme portfolio website, designed for GitHub Pages. The site includes two projects: Automated Checkers Robot and Modular 3-Axis CNC Pen Plotter. It does **not** contain the template's Can Knockdown project or any other template sample projects.

## Files
- `index.html` — portfolio homepage
- `projects/checkers-robot.html` — dedicated Checkers Robot page
- `projects/cnc-pen-plotter.html` — dedicated CNC Pen Plotter page
- `styles.css` — visual styling and mobile layout
- `script.js` — copyright year and gallery pop-up
- `assets/Checkers Robot/` — optimized checkers photos and compressed demonstration video
- `assets/CNC Pen Plotter/` — optimized plotter photos and compressed demonstration video

## Publish on GitHub Pages
1. Create a new repository on GitHub. To make this your primary GitHub Pages site, name it `zsean1119.github.io`. Or use another repo name for a project site.
2. Upload **the files and folders inside this ZIP** to the repository root. Do not upload the enclosing folder instead.
3. In GitHub, go to **Settings → Pages**, choose **Deploy from a branch**, select `main` and `/ (root)`, then save.
4. GitHub Pages will publish the website. The primary site URL is `https://zsean1119.github.io/` for the primary repo name; a different repo will have `https://zsean1119.github.io/<repo-name>/`.
5. The site uses relative links and works with either URL style.
