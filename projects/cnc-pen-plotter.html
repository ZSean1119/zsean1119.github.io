Project 002 / CNC · Mechatronics

Modular 3-Axis
CNC Pen Plotter.

An educational three-axis CNC plotter assembled from modular student-built linear axes, using coordinated stepper-motor motion and a pen toolhead to draw two-dimensional vector graphics.

CNCLinear MotionStepper MotorsRepetier-HostPrototyping
Motion systemX / Y / Z linear axes
Drive methodStepper motors + lead screws
Control interfaceRepetier-Host
01 / Project overview

Turning linear motion into drawings.

This educational prototype brings separately developed linear-axis modules together into a functioning pen plotter. Stepper motors drive lead-screw mechanisms to position paper and a pen in a coordinated working area. The finished system demonstrates how multiple axes can be combined to produce 2D paths on paper.

02 / Mechanical design

Built from modular axes.

  • 01 — Lead-screw motionRotating threaded rods translate motor rotation into controlled movement of the carriages.
  • 02 — Aluminum-extrusion supportsExtrusions provide a rigid base and space for integrating separately fabricated axes.
  • 03 — Pen toolheadA mounted marker provides the drawing point, with a Z-axis mechanism for pen engagement and lift.
  • 04 — Motion coordinationStepper-driven axes are brought together to follow drawing paths using Repetier-Host.
